# Security and public source

Keep environment files, signing keys, service-account credentials, local databases,
network captures, and agent scratch files out of Git. The repository's ignore rules
cover these files, but ignore rules do not remove files already committed.
Phone recordings, uploaded captures, private training data, and pulled deployment
environments belong in ignored local directories or private storage.

Before publishing a branch, scan both its history and its current files with a
secret scanner. For example, with Gitleaks installed:

```sh
gitleaks git --log-opts=--all --ignore-gitleaks-allow --redact=100 .
```

Review new files separately: a Git history scan does not cover uncommitted files.
If a real credential is ever committed, revoke or rotate it even after removing
it from history; other clones and the original repository may retain it.

## Public defaults and client configuration

The `Leaf-Rover` Wi-Fi settings in the firmware, dashboard, and setup guides are
intentional public demo defaults. They are not private network credentials.
Change the password on a real rover before using it outside an isolated demo
network. The firmware's session nonce is not a strong authentication mechanism.

`EXPO_PUBLIC_*` values are embedded in the mobile app. In particular, a configured
`EXPO_PUBLIC_SPLAT_TOKEN` can be extracted from a distributed build: use a token
for the intended demo environment, and keep Redis, Blob, Vercel, and signing
credentials on the server or in private build configuration.

The bundled leaf-floor splat is generated by `frontend/scripts/make-leaf-splat.mjs`.
Wildfire map files derive from the public sources recorded in their coverage
metadata; they are not phone captures or private user records. The OWL-ViT test
image's attribution is recorded in `packages/owlvit/README.md`.

## Publishing mirrors

Deployment workflows are restricted to `SOON-2026/Ember`. Publishing this source
to `leonsilicon/ember` does not copy deployment secrets or enable its production
deployments. Configure a separate environment deliberately before enabling them
elsewhere.
